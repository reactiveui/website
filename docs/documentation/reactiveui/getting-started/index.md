# Getting Started with ReactiveUI

ReactiveUI is a reactive MVVM framework for .NET. A view model describes its properties, commands and errors as
streams, instead of a scatter of event handlers. The view binds to it once and stays in step as values arrive. It
runs on WPF, WinUI, Windows Forms, MAUI, Blazor, Avalonia, Android and Apple platforms.

1. **[Install](installation/index.md)** ReactiveUI for your platform.
2. **Build the [compelling example](compelling-example.md)**, a search screen that ties a view model, a stream-driven
   search, an output property, a command and its view together.
3. **Read the [handbook](../handbook/index.md)** for every topic in depth: view models, commands, data binding,
   scheduling and more.

See [Visual Studio and platform minimums](minimum-versions.md) for the versions ReactiveUI supports.
