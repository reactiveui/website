# Tizen

ReactiveUI ships no Tizen target today. `src/Directory.Build.props` in the ReactiveUI repository lists the
target frameworks each package builds for, and none of them is a Tizen moniker.

Track [pull request #1387](https://github.com/reactiveui/ReactiveUI/pull/1387) for the state of Tizen support,
and the [Tizen platform guideline](../../guidelines/platform/tizen.md) for background.
